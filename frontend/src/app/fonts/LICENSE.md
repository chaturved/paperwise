# Fonts

These files are the Latin subsets of three open-source fonts, served from this repository instead of
Google Fonts so that building the app does not depend on the network.

| File                                          | Family          |
| --------------------------------------------- | --------------- |
| `instrument-sans.woff2`                       | Instrument Sans |
| `newsreader.woff2`, `newsreader-italic.woff2` | Newsreader      |
| `geist-mono.woff2`                            | Geist Mono      |

All three are licensed under the SIL Open Font License, Version 1.1 (https://openfontlicense.org). The copyright
notices are on each family's page at https://fonts.google.com.
